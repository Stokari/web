4Flow 4: Attendant Deactivation & Drain Flow

Owner deactivates → 403 ACCOUNT_DEACTIVATED + drainToken → Device pushes to quarantine → Owner reviews

warningDeactivation Sequence

1Owner: POST /v1/shops/me/members/{id}/deactivate
2Server: membership=DEACTIVATED, revoke tokens & leases
3Attendant device: offline, works until lease expiry (7d max)
4Reconnect: refresh token → 403 + drainToken (10m)
5Device: POST /v1/sync/push with drainToken
6Server: all ops → QUARANTINED, AUTHORIZATION_REVIEW case
7Owner: Accept/Reject each quarantined operation

infoKey Properties

  • • Drain token: 10-min JWT, scope sync:drain
  • • Only allows POST /v1/sync/push and POST /v1/sync/ops/status
  • • Every operation forced to QUARANTINED (zero StockLog effect)
  • • Owner sees Accept (runs handler as original actor) or Reject (archives with reason)
  • • Quarantined ops never deleted — auditable, exportable

check_circleLease Expiry (No Deactivation)

• EXPIRING (24h left): Banner "Offline access ends in N days" + SyncPill warning

• EXPIRED: Read-only mode, protected ops blocked, export still works

• RENEWAL: Online sign-in or lease renewal extends 7 days

• CLOCK ROLLBACK: Device clock backwards >5 min → lease treated as expired

5Token Lifecycle Reference

TokenLifetimeStorageRotationRevocation
Access JWT15 minMemory onlyAsymmetric, kid rotationAuto-expiry; 401 → refresh
Refresh Token30 days maxIndexedDB (hashed)Rotated every use; familyId groupsReuse → family revoked; deactivation
Offline Lease7 days maxIndexedDB (in meta.lease)Renewed online; POST /v1/auth/leaseExpiry, revocation, device mismatch, deactivation
Drain Token10 minutesMemory onlySingle useAuto-expiry; only for deactivated users

Security Notes

  • • Access token in memory only — never in IndexedDB
  • • Refresh token hashed (SHA-256) in DB; familyId tracks rotations
  • • Reuse of rotated refresh token → entire family revoked
  • • Lease validated at push time: membership ACTIVE, device matches, op type allowed
  • • clientCreatedAt outside lease window ±5 min → QUARANTINED (never approves)
  • • CSP: no inline scripts; only Google Identity as third party
