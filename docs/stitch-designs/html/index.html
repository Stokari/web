cheatsheet Quick Reference

block Banned (Zero Tolerance)

  • • Purple/violet gradients
  • • rounded-3xl (24px+) on containers
  • • Glassmorphism / backdrop-blur
  • • Decorative orbs, sparkles, 3D clay
  • • Marketing hero sections in app
  • • Low-density card sprawls
  • • Centered empty states w/ illustrations
  • • Color-only status indicators
  • • Spinners for content loading

check_circle Required (Enforced)

  • • Hairline borders (1px #e2e8f0)
  • • Tabular monospace on ALL numbers
  • • 44px touch targets (54px primary mobile)
  • • Thumb-zone primary actions
  • • Icon + Text badges (never color alone)
  • • Skeleton loading matching layout
  • • Inline errors with Retry button
  • • Compact empty states with CTA
  • • inputmode="numeric/decimal" on qty

keyboard Keyboard Shortcuts (Desktop)

  • Cmd+K Global search
  • Cmd+S Sync now
  • Esc Close modal/drawer
  • Tab Navigate table rows
  • Enter Open row detail
  • Space Toggle selection
